## 1. Documentation

The final report must move beyond "how it works" to "how well it works." It requires empirical data and critical analysis of your system's performance and societal footprint.

### Required Sections

1. **Algorithm Deep-Dive:** This is the core of your technical contribution. Provide a formal mathematical derivation of your custom node using **LaTeX** (e.g., state-space models, prediction/update equations, or Jacobian matrices). You must explicitly map these mathematical variables to the logic and variables found in your source code.
2. **Benchmarking & Results:** Provide empirical evidence of system performance via data visualization. Results should be derived from the "Final Mission" execution:
* **Accuracy:** Time-series or spatial plots comparing **Ground Truth vs. Estimated Pose** (e.g., Odometer vs. EKF output).
* **Error Analysis:** Quantitative data on **Cross-Track Error (CTE)** or the growth of **Covariance Ellipses** over time.
* **Success Rate:** Reliability data across at least **10 trials**. Define your failure modes (e.g., collisions, timeouts, or localization drift).


3. **Ethical Impact Statement:** A 500-word critical analysis covering:
* **Privacy:** Data handling, camera feed management, and face/object blurring measures.
* **Safety:** Evaluation of velocity profiles and kinetic energy management near bystanders or fragile infrastructure.
* **Bias:** Technical limitations of your hardware (e.g., LiDAR's failure to detect glass, dark materials, or IR interference).


4. **Summary Slide:** A single high-impact infographic summarizing the project mission, key algorithm, results, and a snapshot of the robot in action. This will be used for the course gallery.
5. **Live Code Links:** Every custom module mentioned in this report **must** include direct hyperlinks to the specific file and line number in your GitHub repository.

## 2. Technology

The technical portion of this milestone (70% of the MS3 grade) is evaluated based on the **70/30 Technical Model**.

* **Integration Base (70% of Tech Score):** Successful completion of the full mission as defined in Milestone 1. The robot must demonstrate stability and robustness across the entire ROS 2 stack.
* **Algorithmic Factor (30% of Tech Score):** The execution and originality of your custom nodes. This is the implementation of the "Deep-Dive" math into working ROS 2 code.
* **Verification:** Technical contributions will be verified via `git shortlog` and `git blame`.
